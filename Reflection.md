# Project Reflection: SBA Website

## 1. Project Goal
The goal of this assignment was to create the basic HTML structure for my SBA project website. I wanted to build a clean layout that includes a clear header, a navigation menu, a main content section, and a footer with contact information and social media placeholders.

## 2. What Went Well
Setting up the main HTML5 structure went smoothly. I was able to successfully use semantic tags like `<header>`, `<nav>`, `<main>`, and `<footer>` to organize the page logically. Adding the metadata in the `<head>` and creating a working email link (`mailto:`) in the footer were also easy to complete.

## 3. Challenges and Solutions
* **Challenge:** At first, I wasn't sure how to handle having both social media links and copyright information at the bottom of the page. 
* **Solution:** I decided to split them up into two sections at the bottom, using a regular footer tag for the social links and a second footer with a class name (`class="project-footer"`) to keep the copyright info organized.
* **Typo Realization:** I noticed I put the text "Social Links" directly inside the `<ul>` tag instead of putting it in its own list item (`<li>`) or a heading. I plan to fix this small layout mistake next.

## 4. Next Steps
If I had more time to work on this project, I would:
* Create a separate CSS file to add colors, nice fonts, and center the layout.
* Turn the navigation text (Home, About, Contact) into real links that open other pages.
* Replace the placeholder "Lorem ipsum" text with actual content about my project.
